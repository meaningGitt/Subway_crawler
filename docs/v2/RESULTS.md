## 요청의 기대 경향과 다른 결과

각 정차역의 실제 계획 출발시각에 맞춰 30분 혼잡도를 결합했다. 요청의 다섯 예시는 그대로 주입하지 않았고 모두 불일치로 기록했다.

7호선 시간표는 2022-04-30 기준으로 stale이며 혼잡도와 동시 관측이 아니다. 이 값은 현재 운행의 실제 착석 위치로 제공할 수 없다. 시간표 갱신과 실제 착석 관측 검증이 필요하다. 동일한 승차 시간대 혼잡도를 전 경로에 고정하는 방식과 역별 시각 결합 방식은 다른 결과를 낸다.

2호선 신도림→삼성 [07:00,09:00) 41개 운행은 모두 탑승 구간에서 기준선 미도달이다. 일반 29개/신도림 시발 12개를 별도로 표시한다. 09:00 정각 일반 열차를 포함하면 검증 목표 42개가 된다. 하차역 삼성의 다음 구간은 탑승하지 않으므로 기준선 검사에서 제외했다.

월간 평일 보정은 2026-01~06 **같은 역·같은 월**끼리 비교했다. 272역, 29,376개 역·월·시간대 쌍, 08시 계수 중앙값 **1.163689**, 시간대 비중 Pearson 상관 **0.992667**이다. 요청 참고값 0.84/0.986은 이 동일 기간·공휴일 제외 계산에서 재현되지 않았다. 원값을 보존하고 확장 노선 8,280행에는 별도 추정 가중치만 기록했다.

- **확보**: 인천교통공사 시간대 승하차 원본 76,464행(2025-01~2026-06, 인천1·2·7호선), 혼잡도 2,556행(2026 상반기), 상동 포함 7호선 11역 확인. 연구용 원본 다운로드/라이선스 검증 완료, 추천 가공은 아직 미투입.
- **확보**: 2026년 9호선 종합 역별·시간별 혼잡도 XLSX(102,095 bytes), 공공누리1유형. 연구용 원본만 확보.
- **원본 미제공(확인 범위 내)**: 코레일 전체 구간 30분 혼잡도는 찾지 못했다. 확보한 공개 파일은 2018년 최고·첨두 13행이므로 확장 적용하지 않는다.
- **원본 미제공(현재 파일)**: 4호선 05시/23시·남태령 이남 칸 관측. 남태령은 사당 방향만 있다. 호차 번호의 진행방향 정의도 확인하지 못해 앞/뒤를 생성하지 않는다.
- **원본 미제공(목록 확인 범위 내)**: 9호선 2026 일별은 아직 1월이 최신. 2025판을 feature_defaults.json의 기본으로 지정했다.

## 운영 상태

기존 GitHub main 예약 수집의 실제 schedule 성공 실행을 확인했다: [42765559258](https://github.com/meaningGitt/Subway_crawler/actions/runs/42765559258), [42716155592](https://github.com/meaningGitt/Subway_crawler/actions/runs/42716155592). 이는 기존 기본 수집·추천 메타데이터 확인의 성공이며 v2 대용량 자동 누적을 뜻하지 않는다. 예약 시각은 UTC 00:00/13:00 설정이고 실행 지연이 관측된다.

v2는 recommendation.yml에서 수동 전체 수집·실데이터 검증·14일 artifact 보관을 지원한다. 대용량 영구 저장소는 여전히 미설정이다. 특일정보 API 키 없이 공식 정적 달력으로 검증했고, 키를 사용한 실 API 호출은 미검증이다. 빠른하차·실시간·사용자 기록 수집 기능은 이번 정책에 따라 구현하지 않았다.
