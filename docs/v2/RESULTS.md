각 정차역의 실제 계획 출발시각에 맞춰 30분 혼잡도를 결합했다. 요청의 다섯 예시는 그대로 주입하지 않았고 모두 불일치로 기록했다.

7호선은 2022-04-30 구버전을 제외하고 2025-12-31판을 선택했다. 혼잡도 기준일 2026-09와 동시 관측이 아니며 시행일도 미확보다. 이 값은 현재 운행의 실제 착석 위치로 제공할 수 없다. 시간표 갱신과 실제 착석 관측 검증이 필요하다. 추가 대조에서 동일한 승차 시간대 혼잡도를 전 경로에 고정하면 요청의 기대 역 5개가 모두 재현됐다. 따라서 위 불일치는 시간대 결합 방식의 차이로 확인했다. [대조 CSV](fixed_bin_comparison.csv)에 두 방식과 원본 해시를 함께 기록했다. 기본 산출물은 요구사항대로 각 역 출발 시각을 사용한다.

2호선 신도림→삼성 [07:00,09:00) 41개 운행은 모두 탑승 구간에서 기준선 미도달이다. 일반 29개/신도림 시발 12개를 별도로 표시한다. 09:00 정각 일반 열차를 포함하면 검증 목표 42개가 된다. 하차역 삼성의 다음 구간은 탑승하지 않으므로 기준선 검사에서 제외했다.

월간 평일 보정은 2026-01~06 **같은 역·같은 월**끼리 비교했다. 272역, 29,376개 역·월·시간대 쌍, 08시 계수 중앙값 **1.163689**, 시간대 비중 Pearson 상관 **0.992667**이다. 요청 참고값 0.84/0.986은 이 동일 기간·공휴일 제외 계산에서 재현되지 않았다. 원값을 보존하고 확장 노선 8,280행에는 별도 추정 가중치만 기록했다.

## 운영 상태

기존 GitHub main 예약 수집의 실제 schedule 성공 실행을 확인했다: [42765559258](https://github.com/meaningGitt/Subway_crawler/actions/runs/42765559258), [42716155592](https://github.com/meaningGitt/Subway_crawler/actions/runs/42716155592). 이는 기존 기본 수집·추천 메타데이터 확인의 성공이며 v2 대용량 자동 누적을 뜻하지 않는다. 예약 시각은 UTC 00:00/13:00 설정이고 실행 지연이 관측된다.

v2는 recommendation.yml에서 수동 전체 수집·실데이터 검증·14일 artifact 보관을 지원한다. 대용량 영구 저장소는 여전히 미설정이다. 특일정보 API 키 없이 공식 정적 달력으로 검증했고, 키를 사용한 실 API 호출은 미검증이다. 빠른하차·실시간·사용자 기록 수집 기능은 이번 정책에 따라 구현하지 않았다.

누적 내보내기 검증: canonical 시간표·경로·열차 결합 데이터는 최신 완료 스냅샷만 선택하고, 실패 스냅샷·이전 canonical 운행을 복원하지 않는다. 일반 관측의 수정·기간 누적은 유지한다. 실제 trip_seat_line_features export 80행을 확인했다.


## 2026-11-11 재개 확인

[GitHub 전체 수집·가공 실행 42808637205](https://github.com/meaningGitt/Subway_crawler/actions/runs/42808637205)이 2026-11-10 20:50 KST에 성공했다. 공식 파일 17개 다운로드와 가공, 당시 통합 검사 45개, artifact 저장까지 확인했다. 실행 커밋은 `0ade53f826b0b86458906c22cf15f10b5e1fb406`, 클라우드 스냅샷은 `b7acf2702a7c1251f331`이다.

[전체 원본·Parquet·CSV·보고서 artifact](https://github.com/meaningGitt/Subway_crawler/actions/runs/42808637205/artifacts/13761338652)는 197,055,803 bytes이며 2026-11-24 20:50 KST 만료 예정이다. 영구 저장소가 아니다.

그 이후 canonical CSV 내보내기 회귀 검사가 추가됐고 7호선 고정 시간대 대조 검사를 강화했다. 최종 로컬 스냅샷 `5dd5125accecd9cabec3`에서 **46개 전체 검사 통과**를 기록했으며 현재 코드·테스트 해시와 일치함을 재확인했다. 클라우드 실행의 45개 검사와 최종 로컬 46개 검사를 구분한다. 데이터 가공 결과는 동일 정책이며 내보내기/검사 보완을 위해 원본을 재다운로드하지 않았다.

사용자 전달 CSV 묶음: `seat-data/seat_evidence_v2_2026-11-10_csv.zip` (약 56MB). 전체 CSV 45종, 데이터 사전·품질·커버리지·분석 보고서·검사 결과·조사 원본을 포함한다. 데이터 기준일과 다운로드 시각은 각각 원본 기준 필드와 collected_at으로 확인한다. 11월 11일 확인은 11월 10일 데이터의 검증 재개이며 신규 일자의 관측을 수집했다고 표시하지 않는다.

PR #4는 검토 가능한 상태로 올렸으며 아직 main에 병합하지 않았다. 기존 main의 09:00/22:00 예약은 기본 자료 수집·추천 출처 갱신 확인을 계속하고, v2 대용량 전체 가공은 PR 브랜치의 수동 실행으로 검증했다.
