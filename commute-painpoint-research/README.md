# 이동 피로 경험 수집·분석

2026-11-17 기존 지하철 데이터 자동 수집을 중단하고, 통학·통근자의 불편과 실제 행동을 탐색하는 별도 파이프라인으로 전환했다. 기존 좌석 예측 데이터와 합치지 않는다.

## 실제 실행 범위

- Codex의 웹 검색 결과에서 짧은 경험 발췌 79건을 반입했다. 파일럿 40건, 최초 확장 13건, 추가 공개 웹 검색 26건이며 출처당 분석 단위 1개다. 예시 데이터는 없다.
- **최소 200건/목표 300건 본 수집은 미완료**다. 검색 후보 URL 수를 경험 수에 더하지 않는다. 본문 대조는 블로그 1건, 사람의 검토와 발언 진위 독립 검증은 0건이다. 78건은 검색 발췌만 확인했다.
- 새 검색에 Naver API 키를 사용하지 않았다. 검색 도구의 엔진은 확인되지 않았으므로 Google 검색 수집으로 단정하지 않는다. 로그인·CAPTCHA·접근 제한을 우회하지 않았다.
- 검색 결과에 노출된 글·댓글·매체 인용을 구분했다. 검색 발췌를 원문 직접 크롤링이나 공식 API 수집에 성공한 것처럼 표시하지 않는다.
- 직접 자동 수집 허용을 확인하지 못한 커뮤니티에는 요청하지 않았다. 검색 결과만 이용했으며 모든 자료의 재배포 허가를 확보했다는 의미는 아니다. 전체 원문·작성자 이름·닉네임·연락처·프로필을 저장하지 않는다.
- 임베딩 군집화는 미실행이다. 다중 라벨 주제 코딩과 문자 유사도 후보 탐지만 실행했다. 정확한 모델 스냅샷은 세션에서 제공되지 않아 재현 가능한 모델 추출로 주장하지 않는다.

## 재현 실행

저장소 루트에서 아래 명령을 실행한다. Python 3.12 이상, macOS/Linux를 지원한다.

```sh
cd commute-painpoint-research
python3 -m unittest discover -s tests -v
python3 src/analyze.py --phase pilot --out outputs/pilot
python3 src/analyze.py --phase all --out outputs/current
```

이 명령은 **이미 수집한 발췌를 재분석**한다. 실행한 날짜를 새 수집일로 바꾸지 않는다. 입력 파일과 SHA-256 해시, 처리 방법은 `pipeline_lineage.csv` 및 `run_summary.json`에 남긴다. 출력은 UTF-8 BOM CSV로 Excel에서 열 수 있으며 JSON은 보조 제공한다. CSV의 빈 셀은 미확인이지 0이 아니다.

`data/seed/pilot.json`, `expansion.json`, `web_expansion.json`의 행 형식:

```text
[원문URL, 짧은발췌, 사용자유형, 이동목적, 수단, 명시이동시간,
 다중분류(|구분), 명시행동, 불편요약, 확인된게시일]
```

`[…]`는 비연속 발췌 사이의 생략 표시다. 원문 오타는 보존한다. `published_date` 미확인 값은 수집일이나 상대 날짜로 채우지 않는다. `record_id`는 출처 URL 해시이며 사람을 식별하지 않는다. 같은 사람이 다른 글을 썼는지는 확인할 수 없다.

`source_reviews.json`은 본문/댓글 구분, 원문 대조 위치·방법, 명시된 비용·결과 및 제외 사유를 저장한다. 일반 조언, 예정·가정, 창작, 비통근 여행, 삭제 표시 자료, 맥락 부족을 경험과 구분한다. 광고 여부를 확인하지 못한 자료에 광고라는 라벨을 임의로 부여하지 않는다. 미검토 후보는 미분류로 남기며 경험 통계에 포함하지 않는다. URL의 한글 인코딩, 알려진 카테고리 별칭, 모바일 경로를 정규화한다. URL 정규화 규칙이 바뀐 출처의 해시 ID는 이전 출력과 달라질 수 있다.

추가로 플랫폼/사용자/수단 분포 CSV와 4개 Markdown 보고서, 외부 서버 없이 열 수 있는 HTML을 생성한다. 빈 비용·미충족 요구를 임의 추정하지 않는다. 실행한 행동도 해결 성공을 뜻하지 않는다. 매체 인용, 장거리 미확인, 적응 반례가 포함되어 있으므로 필터링 후 해석해야 한다.

## 새 자료의 반복 검색

```sh
# 비밀값은 환경변수/비밀 관리 도구에서 주입한다. .env는 자동 로드하지 않는다.
python3 src/collect.py --config config/keywords.json --out data/live
```

공식 Brave Search API만 지원하며 현재 **실제 API 실행은 미검증**이다. `BRAVE_SEARCH_API_KEY`와 `BRAVE_STORAGE_RIGHTS_CONFIRMED=true`가 없으면 HTTP 요청 전에 종료한다. [Brave 공식 안내](https://brave.com/search/api/)는 결과 저장 권한이 포함된 플랜이 필요하다고 설명하며 [일반 약관](https://api-dashboard.search.brave.com/terms-of-service)은 별도 허용 없는 저장을 제한한다. 실제 계약을 확인해야 한다. API 키만으로 커뮤니티 원문 수집 권한이 생기지 않는다. 이 작업에는 공공 교통 API 키가 필요하지 않다.

라이브 모드는 개인정보를 포함할 수 있는 제목·발췌를 자동 저장하지 않고 **원문 후보 URL만 CSV로 저장**한다. 후보를 검토해 허용되는 최소 발췌와 코딩을 seed 형식으로 반입한 뒤 분석한다. 미검토 후보가 자동으로 유효 사례가 되지 않는다.

- 요청 간격 최소 2초, 429/일시 서버 오류·네트워크 오류는 최대 3회 시도한다.
- 401/403은 재시도하지 않는다. 긴 Retry-After 또는 재시도 소진 429는 배치를 중단한다. CAPTCHA/로그인 우회 없음.
- 쿼리별 성공 상태와 URL 해시를 원자적으로 저장한다. 재실행하면 완료 쿼리는 건너뛰고 실패 쿼리부터 재시도한다. 새 검색 회차는 별도 출력 폴더를 사용한다.
- 로컬 실행 잠금은 프로세스 종료 시 해제된다. 실행 실패는 비정상 종료 코드와 CSV/JSON 로그로 남는다.
- `data/live/`와 생성 출력은 Git에서 제외한다. 자동 분석 Actions artifact는 30일 보관되므로 영구 저장소가 아니다. 현재 짧은 seed는 코드 재현용으로 버전 관리하며 원문 전체를 Git에 누적하지 않는다.

## GitHub Actions 및 기존 수집 중단

`Commute pain-point CSV analysis`는 PR 변경 검증과 수동 실행을 지원한다. 테스트 후 seed를 분석해 CSV artifact를 업로드한다. **새 외부 자료를 자동 수집하는 예약은 등록하지 않았다.** 권한 없는 반복 수집을 작동한다고 표시하지 않는다.

기존 `collect.yml`의 09:00/22:00 KST 예약을 제거했고, 기존 지하철 수집 및 추천 데이터 수집 workflow를 GitHub에서 비활성화했다. 기존 코드·누적 데이터는 삭제하지 않았다. 이 PC에서는 crontab과 관련 launchd 등록을 발견하지 못했다. 다른 서버나 다른 PC의 스케줄은 검증하지 못했다.

## 본 수집에서 남은 일

1. 나머지 78건의 본문 및 30건 표본의 사람 검토. 사람 검토 컬럼은 비워 두었다.
2. 직접 수집 허용 또는 저장 가능한 검색 계약을 확보하고 경험 사례를 200~300건까지 확대. 지금의 부족분이 모두 API 키만으로 해결된다고 보장하지 않는다.
3. 에브리타임·블라인드·네이버 카페 등 미확보 플랫폼의 접근 허가/자발적 인터뷰·설문으로 편향 보완.
4. 앱 리뷰는 실제 통근 경험이 없는 UI 불만을 섞지 말고 별도 표본으로 확보.
5. 모델·버전을 고정한 의미 군집화 및 사람 검토. 현재 범주 빈도만으로 우선 기능이나 시장성을 결론짓지 않는다.
